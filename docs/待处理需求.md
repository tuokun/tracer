# 待处理需求 & 已完成记录

## ⚙️ 设置中增加的内容

### 🎨 主题管理 [已于 v0.2.0 实现]

- **设计**：将色彩配置抽取为 CSS 变量，支持在设置中自由切换主题，并实时分发状态。
- **预设主题**：
  - **极简浅色 (Light)**：经典灰底紫边。
  - **雅致纯白 (Pure White)**：纯白简洁背景。
  - **护眼深色 (Dark)**：舒适深灰蓝色。
  - **深海幽蓝 (Ocean)**：质感深沉暗蓝。
  - **森林护眼 (Forest)**：经典极客暗绿。
  - **跟随系统 (System)**：根据系统明暗模式自动调整。

## 🖥️ 界面与交互优化

### 🔝 主界面顶栏优化 [已于 v0.2.0 实现]

- **设计**：在 `tauri.conf.json` 中配置 `decorations: false` 启用无边框窗口。
- **实现**：前端自定义 `Titlebar` 组件（浮动于顶部、背景透明、完美融合 Sidebar 和主内容区），支持拖动窗口，并提供最小化、最大化、关闭的悬停动效按钮。

### 📄 增加关于页面 [已于 v0.2.0 实现]
