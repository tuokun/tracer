# 项目基本信息

## 项目概述
- **项目名称**：Tracer
- **来源**：Fork 自 [Tai](https://github.com/Planshit/Tai)（C# WPF 时间统计应用）
- **目标**：Rust + Svelte + Tauri 重构，实现极致性能提升
- **核心指标**：后台静默内存目标 < 10MB（上限 < 50MB），CPU 接近 0%
- **目标平台**：仅 Windows 11（不支持 Win10）

## 技术栈
| 层级 | 技术 | 用途 |
|------|------|------|
| 后端 | Rust + Tokio | 窗口监听、数据库 |
| 跨端容器 | Tauri v2 | 桌面应用壳、系统托盘 |
| 前端 | Svelte 5 + TypeScript | UI 界面 |
| 图表 | ECharts | 时间统计图表 |
| 样式 | TailwindCSS | 毛玻璃暗黑 UI |
| 数据库 | SQLite (rusqlite) | 本地数据存储 |

## 开发路线图（v1：5 阶段）
设计见 `重构方案.md`，**可执行构建步骤见 `实现计划.md`**。浏览器网页统计（原阶段三 WebSocket 服务）已推迟到 v2，见 `方案评审记录.md` 二·1。

1. **Rust 监听核心** — `SetWinEventHook` 窗口焦点追踪、UWP 进程提取、WASAPI 音频检测
2. **数据库与存储** — `rusqlite` 建表建索引、flush 策略（事件驱动 + 可配兜底）、WAL 调优
3. **Tauri 系统整合** — 托盘图标、窗口关闭销毁 WebView、开机自启
4. **Svelte 前端 UI** — 毛玻璃暗黑布局、ECharts 图表、分类管理
5. **性能调优** — 内存实测验收、二进制体积优化、最终打包
