# Tracer 前端设计

> 本文档汇总阶段四 Svelte 前端的所有设计决策。设计方向为**任务控制中心**，白色背景 + 靛蓝主色。

---

## 一、设计方向

**定位**：桌面时间追踪仪表盘，强调"此刻正在做什么"的实时感知。

**Signature 元素**：顶部当前应用卡片 + 实时计时器 + 时间轴 NOW 指针。

**风格关键词**：精密、干净、克制、靛蓝。直角骨架 + 微圆角（4px）点缀。

## 四、Layout

### 4.1 整体结构

```
┌─────────────────────────────────────────────────┐
│  ┌──────────┐  ┌──────────────────────────────┐ │
│  │ Sidebar  │  │  Main Content Area           │ │
│  │          │  │                              │ │
│  │  [logo]  │  │  [Current App Card]          │ │
│  │          │  │  [Stats Row]                 │ │
│  │  ◉ 仪表盘│  │  [Time Axis]                 │ │
│  │  ⊟ 统计  │  │  [Ring + App Ranking]        │ │
│  │  ⊞ 应用  │  │  [Heatmap]                   │ │
│  │  ◈ 分类  │  │                              │ │
│  │  ⚙ 设置  │  │                              │ │
│  └──────────┘  └──────────────────────────────┘ │
└─────────────────────────────────────────────────┘
```

### 4.2 侧边栏（Sidebar）

- **展开态**：140px 宽，白底，左侧 3px 靛蓝边框指示 active 项
- **折叠态**：40px 宽，仅图标，鼠标悬停展开文字提示
- **自动折叠**：用户点击主内容区域时自动收缩为迷你模式
- **导航项**：仪表盘（◉）、统计分析（⊟）、应用列表（⊞）、分类管理（◈）、设置（⚙）

### 4.3 圆角

全局 `--radius: 4px`。卡片、按钮、输入框统一小圆角。

### 4.4 阴影

卡片使用极淡阴影：`0 2px 8px rgba(0,0,0,0.05)`。

```
│  │ 自 14:23 开始使用      当前段时长 │  │
│  └───────────────────────────────────┘  │
│  ┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐  │
│  │6h42m │ │chrome│ │1h15m │ │ 7    │  │ ← Stats Row
│  │今日  │ │最常用│ │空闲  │ │应用数│  │
│  └──────┘ └──────┘ └──────┘ └──────┘  │
│  ⋮ 00  03  06  09  12  15  18  21  ⋮  │ ← Time Axis
│           NOW                          │
│  ┌──┐ ┌────────────────────────────┐   │
│  │  │ │ Chrome ████████████  2h18m │   │ ← App Ranking

│  │  │ │ Spotify ██████      1h09m  │   │    list right)
│  └──┘ └────────────────────────────┘   │
│  ███▓▓▓▓▓▓▓▓███▓▓███▓▓▓▓▓▓▓███▓▓▓▓   │ ← 24h Heatmap
│  0     6     12    18                 │
└─────────────────────────────────────────┘
```

### 5.2 当前应用卡片（Hero）

- 背景：`#F8F6FE`（极淡靛蓝），带边框
- 左：应用名（Segoe UI Variable Display SemiBold）+ "自 HH:MM 开始使用"
- 右：实时计时器（JetBrains Mono Medium，靛蓝色）+ "当前段时长" 标签
- 每 1 秒更新一次计时显示
- 窗口切换后立即更新应用名，计时归零从 0 开始

### 5.3 统计行

- 四格平均分布：今日总使用、最常用应用、空闲时间、应用数
- 每格：极浅底色 `#F8F6FE` + 边框
- 数字用 Segoe UI Variable Display SemiBold，标签用 Segoe UI

### 5.4 时间轴（Time Axis）

- 横跨全宽，顶部贯穿线贯穿
- 6 等份标记（00/03/06/09/12/15/18/21），JetBrains Mono tiny
- NOW 指针：靛蓝竖线 + 上方 "NOW" 标签（amber 金 #F5A623 作为唯一点缀）
- 悬浮于时间轴上，指示当前时间的位置

### 5.5 环形图 + 应用排行

- 左：环形图（conic-gradient，应用数显示在中心）
- 右：排行列表，每项 = 应用图标 + 应用名 + 进度条 + 时长 + 分类标签
- 分类标签：小圆角 pill，带分类颜色
- 图标来源：后端从 exe 提取关联图标 (`Icon.ExtractAssociatedIcon`)，存储为 PNG，通过 `icon_path` 返回给前端

### 5.6 24h 热力图

- 24 列网格，每列代表一小时
- 颜色密度 = 该小时内使用时长
- 底部小时标记

## 六、子页面

### 6.1 应用列表

- 搜索/过滤：顶部搜索框
- 表格或卡片列表：应用名、路径、总时长、分类、最近使用时间
- 每行可点击进入应用详情页（v1 可暂缓详情页，仅做列表展示）
- 支持按分类过滤、按时长排序

### 6.2 分类管理

- CRUD 分类：名称、颜色、glob 规则
- 规则语法：glob 通配符（`*`/`?`），匹配 path/process_name/display_name
- 新建分类 → 输入规则 → 保存后对"未手动指派"的 app 重跑规则
- 默认无预置分类，从空开始

### 6.3 设置

- flush 间隔（默认 15min）
- idle 阈值（联动 flush 间隔）
- 开机自启开关（通过 Tauri autostart 插件）
- 数据导出（v1 可延期）

### 6.4 统计分析

**页面入口**：侧边栏"统计"，图标 ⊟。

**页面结构：**
```
┌───────────────────────────────────────────────────────┐
│  统计分析                             2026-07-05      │
│  ○ 日  ○ 周  ○ 月  ○ 年     < [今天] >              │ ← 全局时间选择器
├───────────────────────────────────────────────────────┤
│  ┌──────────────────────────────┐ ┌──────────────┐    │
│  │                              │ │  使用排行      │    │
│  │   24h 柱形图 (3)             │ │  /统计摘要 (1) │    │
│  │   时段使用分布                │ │  最活跃应用    │    │
│  │                              │ │  日均使用      │    │
│  └──────────────────────────────┘ └──────────────┘    │
│  ┌────────────────────────┬────────────────────────┐  │
│  │                        │                        │  │
│  │   分类雷达图 (1)        │   分类饼图 (1)          │  │
│  │   分类对比              │   分类占比              │  │
│  │                        │                        │  │
│  └────────────────────────┴────────────────────────┘  │
└───────────────────────────────────────────────────────┘
```

**时间选择器：**
- 顶部固定，切换粒度（日/周/月/年）+ 日期导航
- 所有图表响应同一时间范围，同步更新

**柱形图（24h 分布）：**
- X 轴：0-23 时
- Y 轴：使用时长（秒/分钟）
- 堆叠模式：每柱按应用堆叠，鼠标悬停显示明细
- 最大值/均值参考线

**雷达图（分类对比）：**
- 每个分类一个顶点
- 维度：该分类的总使用时长
- 支持悬停显示分类名 + 时长数值

**饼图（分类占比）：**
- 环形饼图，每块代表一个分类
- 中心显示分类总数
- 图例列在右侧，带分类颜色圆点

**使用排行/统计摘要：**
- 所选时段的应用排行（Top 5，图标+名称+时长）
- 底部：总时长、最活跃分类、日均使用量

## 八、数据流

### invoke 命令清单

| 命令 | 参数 | 返回 |
|------|------|------|
| `get_today_summary` | — | 总时长、最常用应用、空闲时间、应用数 |
| `get_current_session` | — | 当前前台应用名、开始时间、当前段时长 |
| `get_app_rank` | `{date, limit}` | 应用排行列表（含时长、分类、占比） |
| `get_hourly_heatmap` | `{date}` | 24 小时数组，每项为秒数 |
| `get_app_list` | `{search, category, sort}` | 应用列表（含总时长） |
| `get_categories` | — | 分类列表（含颜色、规则） |
| `save_category` | `{id, name, color, rules}` | — |
| `get_stats_24h` | `{date}` | 24 小时数组（每项为秒数，可选按分类分组） |
| `get_stats_radar` | `{start, end}` | 各分类的时长数组，用于雷达图 |
| `get_stats_pie` | `{start, end}` | 各分类的时长，用于饼图 |
| `get_stats_summary` | `{start, end}` | 总时长、最活跃分类/应用、日均 |
| `get_config` | — | 当前配置 |
| `save_config` | `{key, value}` | — |

### 更新机制
- UI 打开/切换日期时一次性全量拉取
- 后台写库后 `app.emit("data-updated")` 通知前端重拉当前视图
- 前端不做增量 diff

## 九、设计风险与注意

- **字体渲染**：Segoe UI Variable Display 仅 Win11 可用，Cascadia Code 需 Windows Terminal 安装。后备字体链已配置。
- **迷你侧边栏过渡动画**：展开/折叠用 CSS `width` transition + `overflow: hidden`，避免 layout shift。
- **实时计时器**：Svelte 端用 `setInterval(1000)` 更新显示，仅在页面 visible 时运行（`document.hidden` 检测）。
- **热力图渲染**：24×N grid，大数据量时考虑用 Canvas 替代 CSS Grid。
